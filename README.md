# 📚 LearnLink – Full Stack E-Learning Platform

LearnLink is a full-stack web application built using Spring Boot and MySQL that allows students to access structured learning content through a secure and scalable backend system.

This project demonstrates backend architecture design, REST API development, and database integration.

---

## 🚀 Features

### 👩‍🎓 Student Module
- User registration & login
- View available courses
- Enroll in courses
- Track learning progress

### 👨‍🏫 Admin Module
- Add / update / delete courses
- Manage users
- Monitor enrollments

### 🔐 Authentication
- Secure login system
- Role-based access control

---

## 🛠️ Tech Stack

### Backend
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- REST APIs

### Database
- MySQL

### Frontend
- HTML
- CSS
- JavaScript

---

## 🏗️ Architecture

- Controller Layer → Handles HTTP Requests
- Service Layer → Business Logic
- Repository Layer → Database Operations
- MySQL → Data Storage

---

## 🗄️ Database Design

Main Tables:
- Users
- Courses
- Enrollments

Relationships:
- One user can enroll in multiple courses
- One course can have multiple students
